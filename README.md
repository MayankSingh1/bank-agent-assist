# Bank Agent Assist

An AI co-pilot for bank call-center agents. Entry for the **Google AI Builder Cup 2026**, BFSI track (Intelligent Risk, Fraud & Financial Experiences).

When a customer calls, the assistant briefs the agent, listens to the live conversation, spots fraud, dispute and scam signals, and suggests the next action. The agent approves every action, and each one is logged for audit.
